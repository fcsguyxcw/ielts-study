## 二、根因分类（7 题）

**类型 1：NG 与 N/F 混淆（5 题，核心）**
- 1a. **把“原文没提”当 F/N（3 题）**：Q8（没说 fame 原因）、Q25（没说成功与否）、Q38（没说长度影响结果）→ 原文有相关内容但没有题目断言的那个信息 → 一律 NG。
  - 注意：不能只用“反面不成立”推 NG（T 题的正面成立时反面同样不成立）。正确流程是**排除法**：Q8 无 T 证据（原文没提 fame 原因）+ 无 F 证据（也没说“fame 与 size 无关”）→ NG；Q25、Q38 同理。
- 1b. **把"原文已用同义改写明确表态"当 NG（2 题）**：Q6（disappeared = no longer visible）、Q40（small positive relationship = very limited extent）→ 原文**用同义改写把题干内容说死了** → 是 T 不是 NG。
  - 判别口诀：**题干每个信息点，原文都能找到对应表达（哪怕是改写）→ 不是 NG**；NG 是"原文根本没有这个信息点"。

**类型 2：定位/语义冲突（2 题）**
- Q22：支撑句在原文后面（dog 的例子），没定位到就凭"少接触细菌好"的直觉选 Y——**判断题永远先找支撑句，找不到才谈 NG**。
- Q36：`instructed`（被指示）与 `choose`（自主选择）语义冲突，只盯 either...or 漏了动词——**题干的动词比句式更关键**（could choose vs instructed to）。

## 三、解题方法（复测失败后的加强版流程）

### 判定流程（修正版，排除法按顺序执行）

1. **找 T 证据**：原文（含同义改写）有没有**明确支持题目**？→ 有 → **T**（直接结束，不用再查反面）
   - Q6：disappeared = no longer visible → T；Q40：small positive relationship = very limited extent → T
2. **找 F/N 证据**：原文有没有**明确支持题目的反面**？→ 有 → **F/N**
   - Q22：原文说接触细菌有益（题目说少接触好，矛盾）→ N；Q36：instructed（题目说 choose，矛盾）→ F
3. 两步都没有 → **NG**（Q8/Q25/Q38）

> **逻辑修正（2026-08-14 用户提出）**：反面验证法（“题目的反面在原文成立吗？”）只能**确认 F/N**——反面成立 → F/N ✅；反面不成立 → 只能排除 F/N，**不能判 NG**，因为 T 题的正面成立时反面同样不成立（Q6：反面“没消失”不成立，但答案是 T）。判定 NG 必须走排除法：**先查原文是否支持题目（T 证据），再查原文是否支持题目的反面（F 证据），都没有才是 NG**。

### NG 三问（每次判题前强制过一遍，顺序不能乱）

1. **同义改写问**：题干的每个信息点，原文有没有用**别的词**明确支持？→ 有（Q6 disappeared、Q40 small relationship）→ **T**。
2. **反面成立问**：题目的反面，原文**明确成立**吗？→ 成立（Q22 原文说接触细菌有益）→ **N/F**。
3. **无信息确认问**：前两步都没有 → **NG**（Q8/Q25/Q38）。

> ⚠️ 千万不要这样推：反面不成立 → NG（漏掉了“原文支持题目本身”的 T 情况）。

### 判断题做题顺序（固定）

1. **先定位支撑句**（题干关键词回原文找对应句/段），找不到支撑句的题 90% 是 NG 或定位错；
2. **标题干动词**（choose/instructed/believes/efforts）——动词层面的语义冲突最容易漏；
3. **套 NG 三问**，在题目旁边写一个字的理由（改写 T / 反面 N / 矛盾 F / 无信息 NG）；
4. 对答案时**每道判断题必须写推理理由**，不许凭感觉。
