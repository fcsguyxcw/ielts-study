| Q32 | germs→**oil** | `we can kill germs with a disinfectant made from oil extracted from eucalyptus leaves` | **倒序改写**：题干"leaves provide ___ oil which is used to make a disinfectant"先 oil 后 disinfectant，原文反着说；听到 germs/disinfectant（题干后半段锚点）就写 |
| Q35 | forests→**grass / grasses** | `very frequent bushfires... encourages grass to grow... if less frequent... growth of eucalyptus forests` | 题干 high-frequency 被替换为 **very frequent**（形容词替换失锚）；high/low 对比结构，grass=高频结果（前半段）、forests=低频结果（后半段），写了后半段 |
| Q36 | nutrient→**water** | `the fire stops the growth of other species which would consume water needed by eucalyptus trees` | **反向改写**：题干"make more ___ available" = 原文"stops... consume water"（阻止消耗→反推更多可用）；未做反向转化 |
| Q38 | wet→**dry** | `reduced frequency... to low levels has led to what's known as 'dry rainforest'... we associate tropical rainforest with wet conditions` | **引号术语题**：答案 dry 在引号内且在前，紧随其后的解释句（associate...with **wet** conditions）是干扰；听到解释词就写 |
| Q39 | rich→**simple** | `unlike tropical rainforest which is a rich ecosystem, this type of ecosystem is usually a simple one` | **对比结构 unlike A, B**：rich 修饰 A（tropical rainforest，前半句），simple 是答案（句尾）；抓了先出现的形容词 |

## 三、解题方法（本轮专项）

### Part 4 同义替换定位（新增专项，重点）
1. **听前读题分工**：圈出题干里的**名词**（bushfire / eucalyptus / rainforest / bell-miner / trees / vegetation）——这些几乎不被替换，做定位锚；**动词/形容词只做语义预判**（high-frequency → 可能听到 very frequent / frequent...often；ideal environment → 可能听到 find it ideal / perfect for）。
2. **失锚时用名词重锚**：题干形容词没听到别慌，等核心名词（音频里必然出现）→ 听到即锁定段落，回看题干空格前后结构判断答案。
3. **答案选择做结构校验**（本套 4 题栽在这）：
   - 对比结构：`unlike A...B` / `if frequent... if less frequent` → 答案多在后半段，**两个对比项都听完再填**（Q35/39）
   - 同位语：`X bird, which builds its ___` → bird 是修饰词，答案在 which 从句（Q40）
   - 倒序改写：题干先说的在原文后说 → 听到题干后半段锚点词（disinfectant）不等于答案出现（Q32）
   - 引号术语：答案就在引号内，**紧跟其后的解释句是干扰**（Q38 的 wet 紧跟在 dry 后解释"为什么 odd"）
4. **反向改写**：题干"make more available / increase"常对应原文"stops... consume / prevent... using"（Q36），听到 not / stops / prevent / reduce 要反推。

### 双选（第 3 轮强制，连续 3 套 0 分）
1. 听前预读 5 个选项，圈关键词（defend / share / tolerate / apologise...）
2. 每个提到的点**草稿记缩写**（defend→B? put up→D?），听完一段统一配对
3. **必须等到 2 个答案点**：双选对应一段完整论述，第二个常在 but / and / I'd say 后；今天 Q30 只写 1 个选项 = 第二点直接漏掉
4. 常识选项（sharing）多半是干扰：答案必须能在原文找到对应表达

### P2 细节（老账强化）
- 答案句常"答案在句首、干扰在句尾"（Q15 river...harbour）——听完整句再定，不抓最后一个名词
- 近音词校验：听到不确定的词用题干上下文反推（"for local transport" → pass 不是 path）
- 数字题：three/five/four 同时出现时，把每个数字和它的对象绑定（five nights、five meals、three days lunch）
