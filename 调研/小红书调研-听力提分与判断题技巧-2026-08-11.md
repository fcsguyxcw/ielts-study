## 一、听力拼写问题（你的最大失分点）

### 1. 雅思听力答案拼写注意事项（by 天狗老师，B站听力 UP 主）
- 来源：小红书笔记《雅思听力答案拼写注意事项(by 天狗老师)》@卡诺，5761 赞，2024-04-20
- 核心规则（评论区作者答疑）：
  - **单复数写错 = 算错**（"包错的"）
  - **两词答案只写了一个词 = 算错**（"毫无疑问的错"）
  - **冠词 a/the 写混 = 不给分**
  - **机考可以全部大写**，大小写混用也行（誊抄时间 10 分钟）
  - 数字格式宽松：70000 与 70,000 都行；时间写 11.00 而不是 11
  - north east / northeast 写法都算对

### 2. 雅思听力填空词老是拼错咋办？！@Jo9yur66

## 二、Part 3 匹配题（你的第二大失分点）

### 3. 雅思听力 p2p3 邪修方法 @momo
- 3481 赞，2025-12-28，评论区大量验证有效
- 核心方法（读题阶段"盲选法"）：
  1. P2/P3 选择题/匹配题，**读题时先根据常识和逻辑盲选一个答案**（不是纯乱猜，要利用背景知识推）
  2. 这样所有选择题都变成了**判断题**——听的时候"带着答案去核对"，比边听边看选项更专注
  3. **配对题**：播放到左边某个题干时，先把之前填的选项**删掉再听**，防止被乱选干扰，一轮一轮对应
  4. 听完全文仍不确定的题，再回头结合上下文重猜
- 原理：提前盲选能加深对题干和选项的理解（比自己勾勾画画印象深得多），且降低心理压力
- 效果：作者亲测 3 篇从 5-6 个对提高到 8-9 个对
- 评论区补充：P1/P4 靠**刷语料库单词**（王陆语料库），能对 7-8 个
- ⚠️ 反面意见（评论区"数学er"）：盲选可能淡化没选的选项，正确率依赖预猜准确率。**建议：只作为读题策略练习，重点仍是读题时真正看懂题干选项**

## 三、阅读判断题 T/F/NG（你连续四天都错的题型）

### 4. 雅思判断题方法 @别让我走
- 2448 赞，2026-01-11，正文为自存技巧图，评论区干货极多
- 评论区高赞技巧（594 赞）：
  - **判 FALSE 的验证法**：如果判断某题为 FALSE，思考"题目的反面（否定说法）在原文是否成立"——反面成立→FALSE；反面也不成立→NOT GIVEN
- 上下位词法则（27 赞）：**题目用下位词替换原文的上位词 = NG**；用上位词替换下位词 = TRUE
- 共存判断法（21 赞）：**题目和原文能否共存**——能共存就是 NG，矛盾就是 FALSE

## 四、整体提分路径（5 分 → 7 分可复制经验）

### 5. 雅思听力一个月从 5-7.5，我做对了什么 @lately
- 2.4 万赞，2024-02-11，作者高考零听力基础、自测 5 分
- 核心做法：
  - **"考前阅读题目 + 画出题干是听力最重要的一步"**（读题策略 > 盲目听）
  - 刷**王陆语料库 9988**：听写答案词，有时间连同义替换词也听写（两遍）
  - 作者强调纯自学、没报班
- 评论区关键反馈：
  - 有人练 3 个月从 5.5 → 7，"前两个月都在 5.5，**突然有一天**基本全能听懂"（听力提升有量变到质变的临界点，要坚持）
  - 出现"听力不好真的不要精听"（1078 赞）等反方观点——精听要方法正确（听答案句/错题句，不是盲目全文听写），否则低效

## 五、针对你的可操作建议（结合你 8.7-8.11 的错题）

1. **建"听写错词本"**：把你四天拼错的词（disacount、sneack、lockroom、talor、handback、indentificayions、Dymastic 等约 20 个）在爱听写里反复听写，直到全对。拼写规则要记住：单复数、冠词、两词答案不能漏（天狗老师帖）。
2. **P2/P3 读题策略**：下次做题前 5 分钟把题干选项读透画关键词；可试用"盲选法"把选择题变判断题（momo 帖），看是否适合你。
3. **判断题专项**：用"反面验证法"——判 FALSE 前先想反面是否成立；记"上下位词"和"能否共存"两条法则。
4. **听力复盘升级**：你现在"精听听力+看错题"方向对，但建议精听时**只听错题的答案句**并跟读/听写，比全文精听效率高（多篇笔记共识）。
5. **心态**：5→7 有一个月可复制的先例（lately），你有两个月（到 10.12）。听力 5.5-6 阶段往往要持续一阵才突然突破，别因几天没涨分焦虑。
