## 二、方法汇总（多帖交叉共识）

### 0. 题型本质（近水楼台 + 你又不讲理了 + 摸鱼酿酿）
- **Heading = 主旨题（考作者想说什么），Matching = 细节题（考哪段包含某信息）**。方法完全不同，先分清。
- **最大陷阱（三帖共同点名）：拿段落里的原词去配选项里的原词 = "玩连连看"**。选项里出现段落专有名词/常用词，大概率是**错误选项**——那个词只是举例的细节，不是段落重点（你又不讲理了评论区：Alina 悟了"把跟原文出现差不多的单词理解为正常答案，实际上这是坑"）。

### 1. 读段法则（刘洪波 + 摸鱼酿酿 + 顺顺）
- **黄金读段：段首第一句 + 第二句 + 段尾最后一句，70% 主旨在这三句**；不确定再看转折词（however/but/yet）后的句子。
- **带作者态度的句子优先级最高**：surprisingly / unfortunately / problem / optimal measure 这类词后文基本就是段落中心（摸鱼酿酿）。
- 短段落切忌一扫而过：短句大多开门见山抛观点。
- 例外：段落以 for example / in other words 开头 = 解释上一段，主旨跟随上文，不用单独提炼（摸鱼酿酿）。

### 2. 选项处理（顺顺 + 摸鱼酿酿）
- 先看全部选项，把关键词分类：问题 / 原因 / 结果 / 解决方案（摸鱼酿酿五步第一步）。
- **正确答案有总结性、概括性；特别具体/详细的不是答案**（顺顺第 7 条）。
- 关键词只出现一次的段落 → 不是答案；出现两次以上（且可同义替换）→ 是答案（顺顺第 8 条）。
- 含 methodology 的选项慎选：实验步骤不是高频考点，观点和结论才是（摸鱼酿酿）。

### 3. 关键词定位规律（顺顺）
- 选项含 future/consequence/conclusion/prediction → 文章后半部分找
- 选项含 introduction/question/problem/background → 文章前半段找
- 选项含 result/reason/cause → 文章中间部分找
- 选项含 finance/cost → 找出现金钱/符号的段落
- 问号后一般跟主旨句；引号用于解释主旨；it reveals that / I believe that 后是答案

### 4. 排除法（摸鱼酿酿五步第五步）
排除三类错误选项：**① 只描述细节例子 ② 与原文态度相反 ③ 内容属于上一段**。

### 5. 做题顺序（刘洪波 + 近水楼台）
- **先做细节题，最后统一做 Heading**（刘洪波）。
- 细节题（段落信息匹配等）先预览所有题目再读文章；顺序题（判断/填空）平行阅读（近水楼台）。

### 6. 考场步骤（刘洪波）
圈核心词 → 看关键句（首二句/转折/尾句）→ 找同义改写（不是找原词）。

## 三、对照用户 08-17 错题的直接应用

| 错题 | 错因 | 对应方法 |
|---|---|---|
| Q28（iv→vi，被 PR disaster 带偏） | 用段落局部细节词（PR）配选项 | 陷阱警示 + 排除法①：只描述细节例子的选项不选；段落核心是"医生不信任 AI 推荐"（观点） |
| Q30（iii→i，选了 polarise 细节） | 抓了段内细节没上升段主旨 | 概括性优先：polarise（细节）→ society split（主旨 i）；正确选项是"不同说法表达相同意思"而非原词 |
| Q27（i→iii，抓段首 general 句） | 只看首句误选泛化标题 | 黄金读段：首句+次句+尾句；段首 "Many decisions require a good forecast" 是铺垫，核心比较（AI 优于人类预测）在次句 |
| 共性问题 | 选含原文原词的细节项 | 连连看陷阱：选项有段落原词=警惕；先概括段落大意（几个简单词）再匹配 |

**下一步训练**：下套阅读 P3 遇到 heading，强制走"读首二句+尾句+转折后 → 一句话概括 → 同义改写匹配选项（禁原词配对）→ 排除细节/反态度/上段内容"流程。
