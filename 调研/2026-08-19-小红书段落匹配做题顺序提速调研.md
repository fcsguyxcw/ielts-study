## 二、方法汇总（多帖交叉共识）

### 1. 做题总原则（周周女侠 + 猴哥 + momo评论区）
- **绝不全文阅读**，没有时间（周周女侠原则①）。
- **先分清顺序题与乱序题**：判断/填空/单选/人名匹配 = 顺序题（答案按原文顺序出）；**段落信息匹配 = 唯一/主要乱序题**（猴哥评论区：除了段落匹配其他都是顺序题）。顺序题按题号做，乱序题不能按题号找。
- momo 老师教的"先做后面的题、全文读完再匹配"**只适合基础好的考生**；对大多数学生，**平行阅读法（读一段、对一段）更实际**（评论区 13 赞）。

### 2. 平行阅读法（猴哥 + 周周女侠 + 柏拉不画图交叉验证）——直接解决用户"通读一遍再选、遇到新题重新定位"
- **口诀：带两题、读一段、做一题、不回头**（猴哥）。
- 操作：① 先浏览所有题型，只记**前 2 道顺序题**的关键词（不用全部背）；② 从头逐段读文章；③ 读到关键词当场做题，做完一题立刻看下一题；④ **顺便扫一眼这段有没有乱序题（段落匹配）的答案**；⑤ 一段读完不再回头；⑥ 整篇读完，题目也做完。
- 周周女侠版：先做好定位的题（填空→判断→选择→人名匹配），**完成某段的阅读后，同步顺带做该段的 heading/信息匹配**——保证只读一遍全文、不重复阅读。
- 柏拉不画图版：读题→划重点词→按定位词找同义→**每读完一段就跳回对照**（而不是读完所有段再统一回填）。

### 3. 题干关键词怎么划（momo 评论区 31 赞高赞 + 多评论共识）——用户"标关键词"环节的优化
- **划"有辨识度的具体实词"，不要划抽象概括词**：如 misused / turned down / exact / suffered 这类差异含义实词（非等式：划 description 这种抽象词=跟没划一样；要划 misuse bikesharing 这种能联想到具体场景的词）。
- 关键词要有**明确态度或辨识度**（Emma71🌙）。
- **段落匹配本质是同义替换，不是段意概括**——不要总想概括段落大意去找对应，要找题干的同义改写（鸭鸭进京赶烤）。
- 记不住关键词的过渡方案：看完一段再回看一遍题干，开始慢后面会变快（上码头整点薯条）；或草稿纸上写题干中文意思，读一段对照一段（thinker陆）。

### 4. 信息匹配题干的逻辑提示词（周周女侠）
- 关注题干写的是 **an example / a description / a detail / a comparison**——这些词暗示要找的段落类型（例证段/描述段/细节段/对比段），与 08-15 调研"题干压缩成完整考点"互补。

### 5. 配套（柏拉不画图评论区）
- 自建**同义替换积累本**：做真题时积累自己看不出来的同义替换（评论区求资料者众多，说明同义替换是段落匹配最大门槛）。
- 评论区实证：恋爱不如泡脚（四川）"我阅读总是死在匹配题上，看完你的方法实践了一下，正确率真的上去了"。

## 三、对照用户 08-19 错题的直接应用

| 错题 | 错因 | 对应方法 |
|---|---|---|
| P1 Q1（G→B，appealing + not proposing） | 只匹配到 dance 原词，缺"not proposing"否定层 | 题干划"具体实词"：not proposing 属逻辑词要标；按平行阅读逐段对，B 段 not to suggest...however healthy 就是"否定+让步"同义 |
| P1 Q2（F→C，past vs present contrast） | 只匹配到 building，缺对比层 | 题干 comparison 提示词 → 找 Whereas/now 对比段（C 段）；平行阅读时对 Whereas 敏感 |
| P1 Q3（B→F，objective of both） | 只匹配到 aim 类词 | 题干 both 是共同点逻辑 → F 段 shares with engineering the aim 是唯一"共同"表达 |
| P2 Q16（B→D，habitat suffered after extinction） | suffered 原词在 B 段也出现，缺"after extinction"时序 | 划 suffered+extinction 两个点，逐段对；D 段 since the disappearance...have suffered 同时满足两点 |
| P2 Q17（C→A，exact point of extinction） | 缺"精确到日期" | exact 是辨识度实词 → A 段 1 September 1914 日期唯一满足 |

**用户流程诊断**："先标关键词→通读全文→再逐题定位"= 读了两遍以上（通读一遍+逐题重扫），且通读时对逻辑考点不敏感。改为**平行阅读**后：只读一遍，读到段落当场配对。

## 四、结论与待办
- 核心落地：**把做题流程从"通读→逐题重定位"改成"平行阅读（带两题、读一段、做一题、不回头）"**；段落信息匹配不再单独通读全文，而是在读每段时顺带扫。
- 题干关键词升级：划**具体实词+逻辑词**（not/contrast/both/exact/suffered），不划抽象概括词。
- 段落匹配=同义替换，不是段意概括。
